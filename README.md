# NeuroPredict — Neural Network-Based Student Performance Prediction & Academic Risk Detection System

**Tagline:** *"Predict Early. Learn Better. Perform Smarter."*

NeuroPredict is a full-stack Neural Networks and Deep Learning (NNDL) university Project-Based Learning (PBL) platform built with **React + Vite + Tailwind CSS + Recharts**, **Node.js + Express**, **MongoDB + Mongoose ODM**, and a real trainable **TensorFlow.js** Artificial Neural Network.

## 3. Artificial Neural Network Architecture (TensorFlow.js)

- **Topology:** `9 Inputs → 16 Dense (ReLU) → 8 Dense (ReLU) → 1 Dense (Sigmoid)`
- **Total Trainable Parameters:** `305` (`9×16+16 + 16×8+8 + 8×1+1`)
- **Optimizer:** Adam (`learningRate = 0.001`)
- **Loss Function:** Mean Squared Error (`MSE`)
- **Evaluation Metrics:** Mean Absolute Error (`MAE`), `RMSE`, `R²`, and **Split-Conformal 90% Prediction Interval** calibrated strictly on validation residuals.
- **Anti-Leakage Preprocessing:** Z-score standardization statistics (`μ`, `σ`) are computed strictly on the 70% training split before transforming the 15% validation and 15% held-out test splits.
- **Explainability:** Real **Permutation Feature Importance** measured by held-out test-set MAE degradation, plus live neuron-by-neuron forward-pass inspection in the **Neural Network Lab**.
- **Recommendation Engine Disclosure:** Recommendations are generated by a transparent, deterministic **rule-based academic advisor engine** driven by each student's inputs and ANN predicted score (not a second black-box AI model).
- **Synthetic Data Disclosure:** The training pipeline uses a reproducible seeded synthetic dataset (`1,200` records by default) with a nonlinear target relationship + controlled Gaussian noise for educational demonstration. Predictions must not be interpreted as validated real-world exam outcomes.

### 9 Input Features
1. Attendance Percentage (`0–100%`)
2. Internal Examination Marks (`0–100`)
3. Previous Semester GPA (`0–10`)
4. Assignment Completion (`0–100%`)
5. Weekly Study Hours (`0–45 hrs/wk`)
6. Previous Academic Performance (`0–100%`)
7. Subjects Requiring Improvement (`0–8`)
8. Class Participation Score (`0–100`)
9. Current Academic Semester (`1–8`)

## 5. Production Deployment Guide

### Environment Variables (`.env`)
Configure `.env` based on `.env.example`:
- `PORT=3000`
- `NODE_ENV=production`
- `MONGODB_URI="mongodb+srv://<user>:<pass>@cluster.mongodb.net/neuropredict"`
- `JWT_SECRET="<256-bit random hex>"`
- `CORS_ORIGINS="https://your-frontend.vercel.app"`
- `MODEL_STORAGE_DIR="/var/data/neuropredict-model"`

### Model Persistence Strategy on Ephemeral Hosting (Render / Railway / Cloud Run)
Local filesystems on PaaS hosts are often ephemeral and wipe `server/saved-model/` on redeploy:
1. **Persistent Disk (Render Disks / Docker Volume):** Mount a persistent volume at `/var/data/neuropredict-model` and set `MODEL_STORAGE_DIR=/var/data/neuropredict-model`.
2. **Object Storage (S3 / GCS):** Alternatively, upload `model.json`, `weights.bin`, and `metadata.json` to an S3/GCS bucket after training and pull on cold start.
3. **Deterministic Cold-Start Fallback:** If no saved artifacts exist at boot, `neuralNetworkService.initialize()` deterministically trains the seeded `v1.0` model in ~2 seconds before serving traffic.

### Production Build & Start
```bash
npm run build
NODE_ENV=production npm start
```
